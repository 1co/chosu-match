# CHOSU MATCH / ちょすの神経衰弱 🐻🥟

同じ日の「ちょす」を2まいそろえる、ブラウザで遊べる神経衰弱ゲームです。カードのイラストは月ごとに入れ替わります。

## ▶ あそぶ

**https://1co.github.io/chosu-match/**

スマートフォン・PC どちらでも遊べます。

## あそびかた

- カードを2まいめくって、同じ日のちょすがそろえば成功！
- むずかしさは、かんたん（6組）・ふつう（10組）・むずかしい（15組）の3つ
- **ひとりで**：手数とタイムを記録します。ベスト記録はブラウザに自動保存されます。
- **ふたりで**：ちょすチームとにくまんチームが交互にめくります。そろえたら続けてもう一度めくれます。
